STEAL THESE DECKS

Free deck designs for the deck painter. Copy a code, paste it into the game, and wear it in play.

HOW TO USE A CODE

  1. Press COPY CODE under the deck you want.
  2. In the game, open the WARDROBE, pick a hero and press PAINT.
  3. Press PASTE CODE, then DONE. The deck is yours.

Any code fits any hero's deck, and the deck keeps its own shape. The codes work in Rebounded on PC too. Painted one you're proud of? Share its code on the Discord.
